FUNNY VALENTINE (JoJo Part 7) replaces DOORMAN in Deadlock

INSTALL
  1. Unzip this folder anywhere.
  2. Double-click "Install Funny Valentine.bat".
     (If Windows says it protected your PC: More info > Run anyway.)
  3. Start Deadlock and play Doorman.

Deadlock updates turn mod loading off again. If he's back to being Doorman, just
run the installer again. It also updates the mod if you grab a newer zip.

REMOVE
  Double-click "Uninstall Funny Valentine.bat".

ONLY YOU SEE HIM
  Mods are visual only. People without the mod still see Doorman, so
  everyone who wants the president has to install it.

MANUAL INSTALL (if the installer can't find your game)
  - Copy funny_valentine.vpk to  Deadlock\game\citadel\addons\  and rename it
    pakXX_dir.vpk (any number not already used there, e.g. pak42_dir.vpk).
  - Open Deadlock\game\citadel\gameinfo.gi and add the line
        Game    citadel/addons
    right above the line  Game    citadel
  - Or run:  install.ps1 -DeadlockPath "D:\SteamLibrary\steamapps\common\Deadlock"
